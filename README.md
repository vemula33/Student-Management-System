# Student Management System

A simple Student Management System developed using **Java, JDBC, and MySQL**.

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE

## Features
- Add new student records
- Display all student records
- Update student details
- Delete student records
- Search students by ID

## Database Details

Database name: `college`

Table name: `Student`

Columns:
- `student_id`
- `student_name`
- `age`
- `gender`
- `city`
- `marks`

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse.
3. Install MySQL and create the `college` database.
4. Create the `Student` table with the required columns.
5. Add MySQL Connector/J to the project Build Path.
6. Configure your MySQL username and password locally.
7. Run `Main.java`.
